# ocs_doc_api Implementation Plan

> **Implementation status:** This earlier plan has been superseded by the object-model-first design in `1789366410236-ocs-doc-api-object-model-plan.md`. The current crate layout and runtime behavior are documented in `crates/ocs_doc_api/README.md`, `crates/ocs_doc_api/doc/ARCHITECTURE.md`, and `crates/ocs_doc_api/doc/IMPLEMENTATION.md`.

## Goal
Create a low-maintenance, operation-centric, transport-agnostic document API (`ocs_doc_api`) over the existing `acadrust`/`cadkernel` stack and the `OpenCADStudio` host. The API must work both in-process for tests/plugins and across the existing plugin IPC channel.

## Decisions Made
- **New crate:** `crates/ocs_doc_api`.
- **Cargo features:** default `serde`-only; optional `engine` feature pulls in `acadrust`/`cadkernel` and provides entity conversions + `InProcessDocApi`.
- **IPC ownership:** `ocs_plugin_api` owns the request/response enum variants and vtable slot, and depends on `ocs_doc_api` for payload serialization.
- **Public surface:** one object-safe trait `DocApi` with `execute(&mut self, op: DocOp) -> Result<Receipt, DocApiError>`, plus a `DocApiExt` helper trait for typed convenience methods.
- **Wire format:** bincode-encoded `DocOp` and `Result<Receipt, DocApiError>` carried as opaque `Vec<u8>` inside new IPC variants.
- **Full-model access:** `GetDocument` returns and `SetDocument` accepts a lightweight `DocumentSnapshot { name, entities: Vec<(Handle, EntityPayload)> }`. This proves complete document access without coupling the public API to `acadrust` serialization.
- **Solid modeling:** boolean/extrude/shell are implemented on the `OpenCADStudio` host using existing `src/scene/model/solid_model.rs`, `src/scene/model/sweep_model.rs`, and `src/app/model_ops.rs`. The bare-engine `InProcessDocApi` may return `NotImplemented` for kernel ops initially.

## Initial `DocOp` Surface

```rust
pub enum DocOp {
    // Document lifecycle
    CreateDocument { name: String },
    OpenDocument { path: String },
    SaveDocument { path: String },
    CloseDocument,

    // Full-model access
    GetDocument,
    SetDocument { snapshot: DocumentSnapshot },

    // Entity CRUD
    CreateEntity { payload: EntityPayload },
    ReadEntity { handle: Handle },
    UpdateEntity { handle: Handle, payload: EntityPayload },
    DeleteEntity { handles: Vec<Handle> },
    ListEntities,

    // Geometry metrics
    CurveLength { handle: Handle },
    CurveArea { handle: Handle },
    SolidVolume { handle: Handle },
    SolidCentroid { handle: Handle },

    // Solid modeling
    Boolean { op: BoolOp, target: Handle, tool: Handle },
    Extrude { profile: Handle, direction: [f64; 3], distance: f64 },
    Shell { handle: Handle, thickness: f64 },
}
```

## Core Types

```rust
pub struct DocumentSnapshot {
    pub name: String,
    pub entities: Vec<(Handle, EntityPayload)>,
}

pub struct EntityPayload {
    pub kind: String,            // e.g. "point", "line", "circle", "arc", "lwpolyline"
    pub data: serde_json::Value,
}

/// Public handle used by `DocOp`/`Receipt`. It maps to/from the engine's
/// internal handle type (`acadrust::Handle` or `cadkernel::Handle`) via a
/// stable `u64` value. The public wrapper prevents the API from leaking engine
/// types and keeps `ocs_doc_api` serializable without the `engine` feature.
pub struct Handle(pub u64);

pub enum BoolOp {
    Union,
    /// Subtract `tool` from `target` (`target - tool`).
    Difference,
    Intersection,
}

pub enum DocApiError {
    NotFound,
    InvalidPayload(String),
    KernelError(String),
    NotImplemented,
    Io(String),
    /// Failed to serialize a value to the wire format.
    Serialize(String),
    /// Failed to deserialize bytes into a value.
    Deserialize(String),
    Other(String),
}
```

## Traits

```rust
pub trait DocApi {
    fn execute(&mut self, op: DocOp) -> Result<Receipt, DocApiError>;
}

pub trait DocApiExt: DocApi {
    fn create_entity(&mut self, payload: EntityPayload) -> Result<Handle, DocApiError> { ... }
    fn read_entity(&mut self, handle: Handle) -> Result<EntityPayload, DocApiError> { ... }
    fn update_entity(&mut self, handle: Handle, payload: EntityPayload) -> Result<(), DocApiError> { ... }
    fn delete_entity(&mut self, handles: &[Handle]) -> Result<(), DocApiError> { ... }
    fn list_entities(&mut self) -> Result<Vec<Handle>, DocApiError> { ... }
    fn get_document(&mut self) -> Result<DocumentSnapshot, DocApiError> { ... }
    fn set_document(&mut self, snapshot: DocumentSnapshot) -> Result<(), DocApiError> { ... }
    // ... convenience wrappers for every DocOp variant
}
impl<T: DocApi + ?Sized> DocApiExt for T {}
```

1. Append to `PluginRequest`:
   ```rust

   ```
2. Append to `PluginResponse`:
   ```rust
   DocApiResponse { bytes: Vec<u8> },
   ```
3. Add to `HostApi` vtable (end of trait):
   ```rust
   fn doc_api_dispatch(&self, tab_id: TabId, bytes: Vec<u8>) -> Vec<u8>;
   ```
4. Bump `API_VERSION` from `5` to `6` in `crates/ocs_plugin_api/src/manifest.rs`.
5. Provide a typed `DocApiClient`/`DocApiHost` wrapper inside `ocs_plugin_api` that bincode-encodes/decodes and exposes the `DocApi` trait.

## Host Implementations

### 1. `InProcessDocApi` (`ocs_doc_api` / `engine` feature)
- Wraps a bare `acadrust::CadDocument`.
- Implements all CRUD, metrics, and snapshot ops directly on `CadDocument`.
- For `Boolean`, `Extrude`, `Shell`: return `DocApiError::NotImplemented` until kernel-backed implementations are added.
- `UpdateEntity` replaces the entity stored at the given handle, preserving the handle value.
- `CloseDocument` clears the wrapped `CadDocument` (resets to an empty document) but keeps the wrapper alive.
- `OpenDocument`/`SaveDocument` use the engine's native file format if one is stable; otherwise they return `DocApiError::NotImplemented` in-process and are host-only.

### 2. `OpenCADStudio` Host (`src/app/plugin_host.rs`)
- Implement `HostApi::doc_api_dispatch` by:
  1. Decode `DocOp` from bytes.
  2. Locate `app.tabs[tab_id].scene`.
  3. Delegate to existing host logic:
     - CRUD: `Scene::add_entity`, `add_entities`, `update_entity`, `erase_entities`, `SceneEntity` -> `EntityPayload` mapping.
     - Metrics: entity methods + `control_measure` equivalents.
     - Booleans: `src/scene/model/solid_model.rs` `boolean_result` and `src/app/model_ops.rs` boolean grouping.
     - Extrude: `src/scene/model/sweep_model.rs` `extruded`/`extruded_direction`.
     - Shell: `src/app/model_ops.rs` `solid_shell`.
  4. Encode `Result<Receipt, DocApiError>` and return.

## `EntityPayload` ↔ `EntityType` Mapping (engine feature)

Initial primitive conversions only:
- `point` ↔ `Point`
- `line` ↔ `Line`
- `circle` ↔ `Circle`
- `arc` ↔ `Arc`
- `lwpolyline` ↔ `LwPolyline`

Each conversion is a fallible `TryFrom` returning `DocApiError::InvalidPayload` on mismatch. New entity kinds can be added incrementally without breaking the public API.

## CRUD Polyline Example

```rust
use ocs_doc_api::{DocApi, DocApiExt, EntityPayload, Handle};

fn make_polyline(api: &mut impl DocApi) -> Result<Handle, ocs_doc_api::DocApiError> {
    let payload = EntityPayload {
        kind: "lwpolyline".into(),
        data: serde_json::json!({
            "vertices": [
                {"x": 0.0, "y": 0.0, "bulge": 0.0},
                {"x": 10.0, "y": 0.0, "bulge": 0.0},
                {"x": 10.0, "y": 5.0, "bulge": 0.0},
                {"x": 0.0, "y": 5.0, "bulge": 0.0},
            ],
            "closed": true,
        }),
    };
    let handle = api.create_entity(payload)?;

    let read = api.read_entity(handle)?;
    assert_eq!(read.kind, "lwpolyline");

    let mut updated = read.clone();
    updated.data["vertices"][0]["x"] = json!(-1.0);
    api.update_entity(handle, updated)?;

    Ok(handle)
}
```

## Risks and Notes

- The bare-engine backend intentionally returns `NotImplemented` for booleans/extrude/shell. Document this limitation; the host implementation is the production path for solid modeling.
- `EntityPayload` uses JSON `Value` to stay serializable and extensible; numeric precision is preserved via JSON numbers (`f64`).
- Because IPC payloads are opaque bytes, future `DocOp` variants can be added without changing `PluginRequest`/`PluginResponse`, only `API_VERSION` when behavior changes.
- `API_VERSION` bump is required because the vtable gains a new method and old hosts cannot satisfy it.
- `DocumentSnapshot` proves complete document-model access is possible by design; it does not preserve all internal state (render cache, selection, undo) which remains host-specific.

## Out of Scope

- Auto-generation of wrappers for all `acadrust`/`cadkernel` or `/src` functions.
- Replacing the existing JSON `control_request` automation surface.
- UI/selection/command-state integration beyond what `Scene` already exposes.
- ACIS bridge or render-cache serialization.
